

# GameHub Backend 🚀

Backend API for **GameHub**, built with **Node.js + Express + MongoDB**.

## Features

- User Registration
- Secure Password Hashing (bcrypt)
- JWT Authentication
- Protected User Routes
- Wallet Balance Storage
- Admin Dashboard API
- Role-Based Authorization

## Tech Stack

- Node.js
- Express
- MongoDB Atlas
- Mongoose
- bcrypt
- jsonwebtoken
- dotenv
- cors

npm install
